# Foreman 0.4.4

This release adds Pi and Pi Durable attached-session supervision to the Python
core and prepares the separate `@thruwire/foreman-pi` 0.1.0 bridge for npm.

- Normalize Pi lifecycle events and Pi Durable task hooks into Foreman's shared
  supervision runtime through `foreman hook --client pi` and `pi-durable`.
- Route original user submissions, supervise tool calls and results, and apply
  completion feedback through each client's native APIs.
- Preserve work identity and completion allowances through Durable replay and
  retries, with bounded records under Foreman's normal session lifetime.
- Document that Pi supervision requires both the Python core and the TypeScript
  bridge, including source installation and npm installation after publication.
- Prepare the npm bridge with public publishing metadata, Pi gallery keywords,
  an included MIT license, and a build before packing.

The bridges are tested against Pi coding agent and Pi Durable 1.0.4 with Node
22.19+. The npm bridge is released separately from the core; publishing the
Python release does not publish the npm package. Python core 0.4.3 does not
include these Pi adapters. Pi remains an attached-session integration rather
than a worker backend selected by `FOREMAN_WORKER_BACKEND`.
